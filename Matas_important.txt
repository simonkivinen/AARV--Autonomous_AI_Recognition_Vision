1. Skapa den isolerade utvecklingsmiljön
python -m venv .venv

2. Aktivera stöd för långa filnamn i Windows
powershell (admin access requierd)
New-ItemProperty -Path "HKLM:\System\CurrentControlSet\Control\FileSystem" -Name "LongPathsEnabled" -Value 1 -PropertyType DWORD -Force

3. Installera grundläggande bibliotek för Tensorer och Jupyter
.venv\Scripts\pip install torch numpy ipykernel
